Запустить у себя

git clone https://github.com/geekhugged/edu-ab.git
cd edu-ab/app
pip install -r requirements.txt
streamlit run streamlit_app.py

💡 Демо можно бесплатно задеплоить в один клик на Streamlit Community Cloud: укажите репозиторий geekhugged/edu-ab и главный файл app/streamlit_app.py.

С чего начать

Минимальная траектория, если времени мало.

1

Прочитать блок

Откройте модуль на GitHub, пройдите теорию и «Что уметь».

2

Покрутить демо

Запустите соответствующее Streamlit-демо и поиграйте со слайдерами.

3

Сделать практику

Воспроизведите расчёт руками/в коде — только так навык закрепляется.

4

Отметить прогресс

Поставьте галочку в трекере и переходите к следующему модулю.
