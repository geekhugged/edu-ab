# Капстоун-проект

Финальный проект, который собирает все блоки воедино и годится в портфолио.

## Задача
Проведите **полноценный, методологически корректный A/B эксперимент** от гипотезы до решения —
на открытых данных, симуляции или собственном проекте.

## Что должно быть в проекте

1. **Постановка**
   - Бизнес-контекст и продуктовая гипотеза.
   - Primary / secondary / guardrail метрики, обоснование OEC.

2. **Дизайн (до данных!)**
   - Единица рандомизации, схема сплита.
   - Расчёт MDE, размера выборки и длительности (с учётом недельного цикла).
   - Заранее зафиксированный план анализа (какой критерий, α, поправки).

3. **Проверки корректности**
   - SRM-чек, санити-чеки, A/A при возможности.

4. **Анализ**
   - Выбранный критерий, эффект + доверительный интервал.
   - Хотя бы один продвинутый приём (CUPED / sequential / байес — на выбор).
   - Сегментный анализ с поправками, проверка на временные эффекты.

5. **Readout и решение**
   - Чёткая рекомендация: раскатывать / откатывать / итерировать.
   - Честные ограничения и риски.

## Критерии «сдал»
- [ ] Размер выборки посчитан **до** анализа, не подогнан после.
- [ ] Есть CI для эффекта, а не только p-value.
- [ ] Проведён SRM-чек и учтены guardrail-метрики.
- [ ] Применён минимум один продвинутый метод с объяснением, зачем.
- [ ] Вывод понятен человеку без статистического бэкграунда.

## Идеи датасетов
- Открытые датасеты Kaggle с A/B-разметкой (cookie cats, marketing A/B и т.п.).
- Собственная симуляция с зашитым истинным эффектом (проще всего контролировать корректность).
