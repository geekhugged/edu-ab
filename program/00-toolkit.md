# Блок 0. Инструменты и подготовка

**Зачем:** чтобы вся программа считалась руками и в коде, а не оставалась теорией.
Если вы уже уверенно пишете на Python с `pandas`/`numpy` — пролистайте и переходите к Блоку 1.

---

## Цели блока
- Собрать рабочее окружение для расчётов и симуляций.
- Освежить Python для анализа данных.
- Понять базовый SQL — метрики экспериментов почти всегда живут в БД.

## Темы
1. **Окружение:** Python 3.11+, `numpy`, `pandas`, `scipy`, `statsmodels`, `matplotlib`/`seaborn`, Jupyter.
2. **Pandas:** загрузка данных, фильтрация, `groupby`, агрегации, join.
3. **Numpy:** векторные операции, генерация случайных чисел (`np.random`), симуляции.
4. **Визуализация:** гистограммы, boxplot, линейные графики с доверительными интервалами.
5. **SQL (базово):** `SELECT / WHERE / GROUP BY / JOIN`, оконные функции для когорт.

## Что уметь
- Сгенерировать выборку из распределения и построить её гистограмму.
- Посчитать среднее, медиану, стандартное отклонение по группам в `pandas`.
- Написать функцию симуляции (прогнать эксперимент N раз в цикле).

## Практика
```bash
python -m venv .venv && source .venv/bin/activate
pip install numpy pandas scipy statsmodels matplotlib seaborn jupyter
```

**Задание 0.1.** Сгенерируйте 10 000 наблюдений из нормального распределения (µ=100, σ=15),
постройте гистограмму, посчитайте выборочные среднее и σ, сравните с истинными.

**Задание 0.2.** Симуляция подбрасывания монеты: 1000 раз по 100 бросков.
Постройте распределение доли «орлов». Что напоминает форма? (спойлер — ЦПТ, вернёмся в Блоке 1).
