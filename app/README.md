# Интерактивные демо (Streamlit)

Тренажёр к программе [edu-ab](../README.md): по одному интерактивному демо на каждую ключевую тему.

## Запуск локально

```bash
cd app
pip install -r requirements.txt
streamlit run streamlit_app.py
```

Откроется в браузере на `http://localhost:8501`.

## Деплой в облако (бесплатно)

1. Зайдите на [Streamlit Community Cloud](https://streamlit.io/cloud), войдите через GitHub.
2. New app → репозиторий `geekhugged/edu-ab`, ветка `main`, главный файл `app/streamlit_app.py`.
3. Deploy. Через минуту получите публичную ссылку — её можно добавить на GitHub Pages лендинг.

## Демо по темам

| Демо | Блок / модуль | Что показывает |
|------|---------------|----------------|
| 📊 ЦПТ и ЗБЧ | 1.3 | как среднее любого распределения становится нормальным; `SE=σ/√n` |
| 📏 Доверительные интервалы | 1.4 | смысл «95%» на симуляции + bootstrap vs формула |
| 🎯 Проверка гипотез | 1.5 | α, β, мощность на картинке; A/A-симуляция ошибки I рода |
| 🧮 Калькулятор выборки | 2.4 | MDE ↔ размер выборки ↔ длительность, квадратичный рост |
| ⚖️ Статкритерии | 2.5–2.6 | z-тест долей и t-тест Уэлча + CI для эффекта |
| 👀 Проблема peeking | 3.1 | как подглядывание раздувает ложные срабатывания |
| 🔀 SRM-чек | 3.3 | χ²-проверка соотношения групп |
| 🎛️ Множественные сравнения | 3.2 | Bonferroni vs Benjamini–Hochberg (FDR) |
| ⚡ CUPED | 4.1 | снижение дисперсии и сужение CI при той же выборке |
| 🃏 Байес и бандиты | 4.3–4.4 | P(B>A), ожидаемые потери; Thompson Sampling и regret |

## Структура

```
app/
├── streamlit_app.py      # точка входа + навигация (st.navigation)
├── requirements.txt
└── demos/                # по файлу на демо
    ├── 01_clt.py
    ├── 02_confidence_intervals.py
    ├── ...
    └── 10_bayes_bandits.py
```

Требуется Streamlit ≥ 1.36 (используется `st.navigation` / `st.Page`).
