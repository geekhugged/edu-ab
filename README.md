# edu-ab — Программа прокачки в A/B тестировании

Самоучебная программа: от **фундамента по статистике** до **продвинутых глав** A/B тестирования.
Рассчитана на самостоятельное прохождение с упором на практику (Python + реальные датасеты).

> Цель программы: научиться **проектировать, запускать и корректно интерпретировать** A/B эксперименты,
> понимать статистику «под капотом» и не наступать на типовые грабли, которые делают выводы недостоверными.

---

## Как пользоваться

1. Идите по блокам сверху вниз — каждый опирается на предыдущий.
2. В каждом модуле есть: **Цели → Темы → Что уметь → Практика → Ресурсы**.
3. Не пропускайте практику. A/B тестирование — навык, а не знание. Считайте руками хотя бы раз.
4. Отмечайте прогресс в [`program/progress.md`](program/progress.md).
5. Все ссылки на литературу и курсы — в [`program/resources.md`](program/resources.md).

**Формат работы над модулем:** прочитать теорию → повторить формулу руками на маленьком примере →
воспроизвести в Python (scipy/statsmodels) → сделать мини-проект блока.

## Что вы будете уметь на выходе

- Формулировать гипотезы, выбирать метрики (primary / guardrail / OEC).
- Рассчитывать размер выборки, MDE и мощность **до** запуска.
- Правильно выбирать статистический критерий и строить доверительные интервалы для эффекта.
- Распознавать и предотвращать peeking, SRM, множественные сравнения, парадокс Симпсона.
- Применять продвинутое: CUPED, sequential testing, байесовский подход, бандиты, switchback, uplift.
- Читать статьи Netflix / Microsoft / Booking / Airbnb об экспериментах и понимать их насквозь.
